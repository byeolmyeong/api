# 나의 일 방식 막대 셋 — 공식

> 쓰이는 곳: 서버 결정 038(일 방식 수치는 서버가 차트로 계산) · 나 탭 풀이 `GET /me-report` 의 WORK 영역 `workStyle { together, flexible, fast }` · 앱 결정 048(나 탭, 막대 자리에 점만 그림) · 원본: 앱 저장소 `docs/raw/2026-11-20-session-owner-qna-home-me-timing.md` 11번 · 시안: 보드 12-11 "나 탭 · 일"

## 1. 막대 셋과 값의 뜻
| 칸 | 왼쪽(0 쪽) | 오른쪽(100 쪽) |
|---|---|---|
| `together` | 혼자서 | 함께 |
| `flexible` | 계획대로 | 그때그때 |
| `fast` | 꼼꼼하게 | 빠르게 |

- 값은 **왼쪽 끝에서 잰 점의 위치**(정수 10~90)다. 시안의 "32%" 는 점이 왼쪽에서 32% 자리에 있다는 뜻 — "혼자서" 쪽에 가깝다.
- 같은 차트면 언제나 같은 값이다(모델이 쓰지 않는다 — "숫자는 서버 코드가 계산한다", 골든 룰 · 결정 002).
- 시안의 32 · 30 · 38 은 그림의 예시 값이고 이 공식으로 나온 값이 아니다.

## 2. 재료
### 무게 (점 하나가 얼마나 세게 세어지나)
| 점 | 무게 | 이유 |
|---|---|---|
| 해 · 달 | 3 | 나의 중심과 마음 — 성향을 가장 크게 정한다 |
| 수성 · 금성 · 화성 | 2 | 생각 · 좋아함 · 움직이는 방식, 사람마다 많이 다르다 |
| 목성 · 토성 | 1 | 한 별자리에 한두 해 머물러 또래끼리 비슷하다 |
| 천왕성 · 해왕성 · 명왕성 | 0.5 | 몇 해~십몇 해 머물러 같은 세대가 거의 같다 |
| 상승점 | 2 | 밖으로 드러나는 행동 방식(시각을 알 때만) |
| 중천 | 1 | 일의 지향(시각을 알 때만) |

행성 무게 합은 15.5, 시각을 알면 상승점 · 중천을 더해 18.5 다.

### 몫
- **원소 몫** F(불) · E(흙) · A(공기) · W(물) = 그 원소의 별자리에 놓인 점의 무게 합 ÷ 전체 무게. 불 = 양 · 사자 · 사수, 흙 = 황소 · 처녀 · 염소, 공기 = 쌍둥이 · 천칭 · 물병, 물 = 게 · 전갈 · 물고기.
- **성질 몫** C(시작) · X(고정) · M(변화) = 같은 방식. 시작 = 양 · 게 · 천칭 · 염소, 고정 = 황소 · 사자 · 전갈 · 물병, 변화 = 쌍둥이 · 처녀 · 사수 · 물고기.
- **하우스 몫** H{집합} = 그 하우스들에 놓인 행성(상승점 · 중천 빼고)의 무게 합 ÷ 15.5. 시각을 알 때만.
- **일하는 별의 원소 값**: 불 1 · 공기 ½ · 물 −½ · 흙 −1.

## 3. 축마다의 식
모든 축은 −1~1 사이의 r 을 만들고, **값 = round(clamp(50 + 50 · r, 10, 90))** 이다(0.5 는 올림).

### 축 1 — 혼자서 → 함께 (`together`)
- 원소 e1 = (A + ½F) − (W + ½E)
  - 공기는 말과 교류, 불은 밖으로 나서는 힘이라 "함께" 쪽. 물은 안으로 느끼고 가까운 몇 사람과 깊어지는 결, 흙은 혼자 손으로 다지는 결이라 "혼자서" 쪽. 불 · 흙은 반만 센다(사람보다 일 자체에 가까운 성질).
- 하우스 h1 = H{3, 7, 11} − H{4, 8, 12}
  - 3(이웃 · 오가는 말) · 7(마주 앉는 사람) · 11(모임 · 동료)은 함께하는 자리, 4(집 · 뿌리) · 8(깊고 둘만의 것) · 12(숨은 자리 · 혼자의 시간)는 혼자의 자리.
- 시각 앎: r = 0.65 · e1 + 0.35 · h1 / 모름: r = e1

### 축 2 — 계획대로 → 그때그때 (`flexible`)
- 성질 m2 = M − X
  - 변화 별자리는 바뀌는 상황에 맞춰 가는 성질, 고정 별자리는 정한 것을 지키고 이어 가는 성질. 시작 별자리는 "먼저 움직인다" 는 성질이라 이 축에서는 어느 쪽도 아니다(축 3 에서 쓴다).
- 원소 e2 = ½ · (F + A − E − W)
  - 불 · 공기는 가볍게 옮겨 가고, 흙 · 물은 쌓고 지킨다. 성질보다 약하게 센다.
- 하우스 h2 = H{3, 9} − H{2, 6, 10}
  - 3 · 9 는 배움 · 이동 · 넓은 곳의 자리라 그때그때, 2 · 6 · 10(가진 것 · 매일의 일 · 맡은 자리 — 흙의 하우스)은 틀과 순서의 자리라 계획대로.
- 시각 앎: r = 0.55 · m2 + 0.25 · e2 + 0.20 · h2 / 모름: r = 0.70 · m2 + 0.30 · e2

### 축 3 — 꼼꼼하게 → 빠르게 (`fast`)
- 원소 e3 = (F + ½A) − (E + ½W)
  - 불은 곧장 움직이고 공기는 빨리 판단한다(반만). 흙은 정확하게 다듬고 물은 느끼며 천천히 간다(반만).
- 성질 m3 = C − X
  - 시작 별자리는 먼저 손을 대고, 고정 별자리는 오래 붙들고 끝까지 다듬는다.
- 일하는 별 p3 = (화성의 원소 값 + 수성의 원소 값) ÷ 2
  - 화성은 움직이는 방식, 수성은 생각하고 처리하는 방식이라 일의 속도를 직접 말한다.
- 하우스 h3 = H{1, 3} − H{6, 8}
  - 1(나서는 나) · 3(빠른 오감)은 빠르게, 6(일의 세부 · 매일의 순서) · 8(깊이 파고듦)은 꼼꼼하게.
- 시각 앎: r = 0.40 · e3 + 0.25 · m3 + 0.20 · p3 + 0.15 · h3 / 모름: r = (0.40 · e3 + 0.25 · m3 + 0.20 · p3) ÷ 0.85

## 4. 시각 "모름" 일 때
- 상승점 · 중천을 재료에서 뺀다(전체 무게 15.5). 하우스 항(h1 · h2 · h3)을 뺀다(골든 룰: 시각을 모르면 하우스 · 상승점은 계산할 수 없는 값).
- 남은 항의 가중치는 합이 1 이 되게 다시 나눈다.
  - 축 1: 0.65 → 1.
  - 축 2: 0.55 · 0.25 → 0.6875 · 0.3125 를 **0.70 · 0.30 으로 반올림했다**(초안 값). 정확히 나눠도 아래 두 예의 결과는 같다(29 · 65). 구현 때 정확한 값으로 바꿀지는 소유자가 볼 것 3.
  - 축 3: 0.85 로 나눈다(정확).
- 그래서 같은 사람도 시각을 알 때와 모를 때 값이 다를 수 있다(예 1). 앱은 값만 그린다.

## 5. 10~90 으로 자르는 이유
- 0 이나 100 은 "완전히 혼자서만 일하는 사람" 처럼 단정으로 읽힌다. 점성술은 기울기를 말할 뿐이라 양 끝을 비워 둔다.
- 한 원소 · 한 성질에 점이 몰린 차트에서는 r 이 ±1 에 가까워져 끝에 붙기 쉽다. 자르면 그런 차트도 "많이 기운 쪽" 으로만 보인다.

## 6. 계산 예
가짜 차트다(사람의 출생 정보가 아니다). 숫자는 스크립트로 계산했다: `python3 -I workstyle.py`(이 세션의 임시 폴더, 구현 때 테스트 값으로 옮긴다).

### 예 1 — 시안의 인물을 흉내 낸 차트(시각 앎)
해 물병 5하우스 · 달 염소 4 · 수성 물병 5 · 금성 물병 5 · 화성 염소 4 · 목성 사자 11 · 토성 황소 8 · 천왕성 염소 4 · 해왕성 염소 4 · 명왕성 전갈 2 · 상승점 천칭 · 중천 게

1. 무게 합 18.5. 원소: 불 1(목성) · 흙 7(달 3 · 화성 2 · 토성 1 · 천왕성 ½ · 해왕성 ½) · 공기 9(해 3 · 수성 2 · 금성 2 · 상승점 2) · 물 1.5(명왕성 ½ · 중천 1) → F 0.054 · E 0.378 · A 0.486 · W 0.081.
2. 성질: 시작 9(달 · 화성 · 천왕성 · 해왕성 · 상승점 · 중천) · 고정 9.5(해 · 수성 · 금성 · 목성 · 토성 · 명왕성) · 변화 0 → C 0.486 · X 0.514 · M 0.
3. 하우스 무게(행성만, ÷ 15.5): 2하우스 0.5 · 4하우스 6 · 5하우스 7 · 8하우스 1 · 11하우스 1.
4. 축 1: e1 = (0.486 + 0.027) − (0.081 + 0.189) = 0.243. h1 = H{3,7,11} 0.065 − H{4,8,12} 0.452 = −0.387. r = 0.65 · 0.243 + 0.35 · (−0.387) = 0.023 → 50 + 1.2 = **51**.
5. 축 2: m2 = 0 − 0.514 = −0.514. e2 = ½ · (0.054 + 0.486 − 0.378 − 0.081) = 0.041. h2 = H{3,9} 0 − H{2,6,10} 0.032 = −0.032. r = 0.55 · (−0.514) + 0.25 · 0.041 + 0.20 · (−0.032) = −0.279 → 50 − 14.0 = **36**.
6. 축 3: e3 = (0.054 + 0.243) − (0.378 + 0.041) = −0.122. m3 = 0.486 − 0.514 = −0.027. p3 = (화성 염소 −1 + 수성 물병 ½) ÷ 2 = −0.25. h3 = H{1,3} 0 − H{6,8} 0.065 = −0.065. r = 0.40 · (−0.122) + 0.25 · (−0.027) + 0.20 · (−0.25) + 0.15 · (−0.065) = −0.115 → 50 − 5.8 = **44**.
7. 결과 **51 · 36 · 44** — 혼자서와 함께의 가운데, 계획대로 쪽, 조금 꼼꼼한 쪽. 4 하우스에 별이 많아(혼자의 자리) 공기의 "함께" 가 상쇄되고, 고정 별자리가 많아 계획대로 쪽이다.

같은 차트를 **시각 모름** 으로 계산하면(상승점 · 중천 · 하우스 뺌, 무게 합 15.5):
- F 0.065 · E 0.452 · A 0.452 · W 0.032, C 0.387 · X 0.613 · M 0.
- 축 1: r = e1 = 0.226 → **61**. 축 2: m2 −0.613 · e2 0.016, r = 0.70 · (−0.613) + 0.30 · 0.016 = −0.424 → **29**. 축 3: e3 −0.177 · m3 −0.226 · p3 −0.25, r = (−0.071 − 0.057 − 0.050) ÷ 0.85 = −0.209 → **40**.
- 결과 **61 · 29 · 40** — 하우스 항(4하우스 쏠림)이 빠져 "함께" 쪽으로 옮겨 간다.

### 예 2 — 불이 많은 차트(시각 모름)
해 양 · 달 쌍둥이 · 수성 양 · 금성 물고기 · 화성 사자 · 목성 사수 · 토성 처녀 · 천왕성 물병 · 해왕성 물병 · 명왕성 사수

1. 무게 합 15.5. 원소: 불 8.5(해 3 · 수성 2 · 화성 2 · 목성 1 · 명왕성 ½) · 흙 1(토성) · 공기 4(달 3 · 천왕성 ½ · 해왕성 ½) · 물 2(금성) → F 0.548 · E 0.065 · A 0.258 · W 0.129.
2. 성질: 시작 5(해 · 수성) · 고정 3(화성 · 천왕성 · 해왕성) · 변화 7.5(달 · 금성 · 목성 · 토성 · 명왕성) → C 0.323 · X 0.194 · M 0.484.
3. 축 1: e1 = (0.258 + 0.274) − (0.129 + 0.032) = 0.371 → 50 + 18.5 = **69**.
4. 축 2: m2 = 0.484 − 0.194 = 0.290. e2 = ½ · (0.548 + 0.258 − 0.065 − 0.129) = 0.306. r = 0.70 · 0.290 + 0.30 · 0.306 = 0.295 → **65**.
5. 축 3: e3 = (0.548 + 0.129) − (0.065 + 0.065) = 0.548. m3 = 0.323 − 0.194 = 0.129. p3 = (화성 사자 1 + 수성 양 1) ÷ 2 = 1. r = (0.40 · 0.548 + 0.25 · 0.129 + 0.20 · 1) ÷ 0.85 = 0.531 → 50 + 26.5 = **77**.
6. 결과 **69 · 65 · 77** — 함께 · 그때그때 · 빠르게 쪽. 불과 변화 별자리가 많고 화성 · 수성이 둘 다 불이다.

## 7. 서버 구현 자리 (결정 038, 계획 묶음 S②)
- `chart/WorkStyle.kt` 의 순수 함수 하나: `computeWorkStyle(chart: Chart): WorkStyle` → `WorkStyle(together: Int, flexible: Int, fast: Int)`. 차트 계산은 `chart` 패키지에서만(골든 룰). 별자리는 `positions[].sign`, 하우스는 `positions[].house`, 상승점 · 중천은 `chart.houses` 가 있을 때 `signOf(ascendant)` · `signOf(midheaven)`.
- 반올림은 0.5 올림(`roundToInt()`). 스크립트(파이썬 `round`, 짝수 쪽 반올림)와 0.5 에서만 다르다 — 예의 값은 0.5 에 걸리지 않는다.
- 나 탭 풀이의 WORK 영역을 저장할 때 이 값을 함께 넣는다. 모델에게는 주지 않는다(글이 숫자를 말하지 않게 — 숫자는 서버만 말한다).
- 테스트(`WorkStyleTest`, 실패를 먼저 본다):
  - 예 1 시각 앎 → 51 · 36 · 44, 같은 차트 시각 모름 → 61 · 29 · 40, 예 2 → 69 · 65 · 77.
  - 모든 점이 한 별자리(예: 양)에 몰린 차트 → 세 값 모두 10 이상 90 이하.
  - 같은 차트를 두 번 → 같은 값. 시각 모름 차트에서 하우스 값을 바꿔도 결과가 같다(하우스를 읽지 않는다).

## 소유자가 볼 것
1. 막대마다 어떤 원소 · 성질 · 하우스를 어느 쪽에 두었는지(3절의 한 줄 이유) — 점성술 뜻과 맞는지.
2. 무게(해 · 달 3, 바깥 행성 ½ 등)와 축마다의 가중치(0.65 · 0.35 등).
3. 시각 모름의 축 2 가중치를 0.70 · 0.30(초안)으로 둘지 정확한 0.6875 · 0.3125 로 둘지 — 두 예의 결과는 같다.
4. 10~90 으로 자르는 범위(더 좁게 20~80 도 가능).
5. 예 1 처럼 시각을 알 때와 모를 때 값이 달라지는 것을 받아들일지(기본값: 받아들인다 — 하우스는 시각을 알 때만 계산할 수 있다).
