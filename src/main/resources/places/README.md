# kr-sigungu.csv — 국내 시·군·구 229곳의 이름과 좌표

- 출처: GeoNames(https://www.geonames.org) 의 국가별 덤프 `https://download.geonames.org/export/dump/KR.zip`, 2026-11-10 내려받음. 라이선스 CC BY 4.0.
- 만든 방법: `KR.txt` 에서 feature code 가 `ADM2` 인 행(229개)의 `geonameid`·`latitude`·`longitude` 를 그대로 옮겼다. 이름은 그 행의 `alternatenames` 가운데 한글 이름(…시·…군·…구)에 시·도 이름을 붙였다. 세종특별자치시는 하위 시·군·구가 없어 `ADM1` 행(8394437)을 썼다.
- 좌표는 GeoNames 가 주는 그 행정구역의 대표점이다(시청·구청 위치가 아닐 수 있다). 고치지 않았다.
- 열: `id`(GeoNames geonameid) · `name` · `lat` · `lon`(도, 동경·북위가 양수).

## 원본과 다르게 손댄 곳 (이름만. 좌표는 원본 그대로)
- 8659242 (Sejong-Si, ADM2): 세종 ADM1 행과 겹쳐서 뺐다.
- 8417631 (Gyeyang-gu): 원본에 한글 이름이 없어 `인천광역시 계양구` 로 적었다.
- 8604983 (Michuhol): 원본에 `남구`·`미추홀구` 가 함께 있어 지금 이름 `미추홀구` 를 골랐다.
- 1842015 (Gunwi-gun): 원본은 경상북도 소속이다. 2023-07 편입에 맞춰 `대구광역시 군위군` 으로 적었다.
- 시·도 이름은 지금 이름(강원특별자치도·전북특별자치도·제주특별자치도)으로 붙였다.

## 알려진 빈틈
- 2026-07 인천 행정구역 개편(제물포구·영종구·검단구 신설)은 원본에 없어 넣지 않았다. 옛 이름(중구·동구·서구)으로 실려 있다.
- 일반구(수원시 장안구 같은 시 아래의 구)는 원본에서 `ADM3` 이라 넣지 않았다. 시 단위로 고른다.
